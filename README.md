# AI SaaS Product Analytics Platform

## Overview

AI SaaS Product Analytics Platform is a production-style real-time data engineering project that simulates telemetry generated by modern AI applications such as ChatGPT, Claude, Gemini, Perplexity, Cursor AI, and Notion AI.

The platform captures AI user events, streams them through Apache Kafka, processes them using Apache Spark Structured Streaming, stores them in a Lakehouse architecture (Bronze, Silver, Gold), orchestrates pipelines with Apache Airflow, models analytics using dbt, and visualizes business KPIs in Power BI.

---

## Business Problem

Modern AI companies generate billions of events every day.

Examples include:

- User Login
- Chat Started
- Prompt Submitted
- Response Generated
- Tokens Consumed
- Latency
- API Cost
- Subscription Upgrade
- Errors

The objective of this project is to build a scalable analytics platform capable of processing these events in real time.
